# Voice Standards and Artifact Templates

HeyHi voice standards for all futurecasting content, and templates for each deliverable artifact.

---

## Voice Standards

### The Core Register

Warm. Direct. Specific. Not academic. Not corporate. Conversational — the way a trusted advisor with deep expertise speaks in the room.

**Sounds like:**
- "What does your team actually need?"
- "We build it in from the start."
- "That shouldn't be automated."
- "This is the work — not 'you've been doing it wrong.'"
- "What does a Tuesday look like, specifically?"

**Never sounds like:**
- "We unlock new paradigms of operational efficiency."
- "We'll supercharge your workflow."
- "End-to-end digital transformation."
- "We leverage cutting-edge technology to empower your team."

### The Two-Letter Word

Never use "AI" as a standalone word or prefix in HeyHi-authored content. Describe what the system does — not what category it belongs to.

- Not: "AI-powered design systems" → Instead: "design systems that adapt as your organization grows"
- Not: "AI tools for automation" → Instead: "the systems doing the work your team used to do manually"
- Not: "AI consulting" → Instead: "intelligent infrastructure consulting" or "systems strategy"

If a client uses "AI" in their own materials, do not correct them in their documents — but do not echo it in HeyHi-authored content.

### Em Dash Rule

Avoid em dash overuse. Em dashes are a recognized pattern of AI-generated writing and undermine the crafted voice. Maximum one per document; two is the absolute limit.

- Not: "We build systems — living, adaptive systems — that fit how you actually work."
- Instead: "We build living, adaptive systems that fit how you actually work."

### What to Avoid

| Pattern | Fix |
|---|---|
| "AI" | Describe the function |
| Em dash overuse | Restructure the sentence |
| "Comprehensive" | Name what it actually covers |
| "Delve" / "dive into" | "Look at," "examine," "work through" |
| "At its core" | Start with the substance |
| "Robust" | Say what it actually does |
| "Leverage" | "Use," "apply," "build on" |
| Abstract future tense | Specific, concrete, grounded |
| "Seamless" | Name what's smooth about it |
| "Holistic" | Name the actual scope |
| "Empower" | Name what they can now do |

## The Translation Guide

| Methodology term | HeyHi language | When to use |
|---|---|---|
| Backcasting | The Preferred Future method | Workshop descriptions, exercise instructions |
| Weak signals | Organizational early warning | Signal Readers workshop, client reports |
| Scenario planning | Divergent futures mapping | Before You Build workshop, strategy work |
| Pre-mortem | Before You Build analysis | Workshop titles, pre-implementation work |
| "Give Yourself an A" | The Letter exercise | Exercise instructions, workshop materials |
| Futurecasting Canvas | The Working Canvas | Deliverable descriptions, Consult layer |
| Horizon scanning | Field reading / Context mapping | Thought leadership, conference materials |
| Futurecasting | Strategic foresight / Designing the future | Consult service description, talks |
| Strategic drift | The current trajectory | Working Canvas framing |
| Signal severity | How loud this is getting | Signal Map assessments |
